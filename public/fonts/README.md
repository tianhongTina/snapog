# Fonts Directory

Place font files here for use with @vercel/og (Satori) templates.

## Required fonts for OG image generation:

- `inter-regular.ttf` - Inter Regular (download from Google Fonts)
- `inter-bold.ttf` - Inter Bold (download from Google Fonts)
- `roboto-mono-regular.ttf` - Roboto Mono Regular (for code-style template)

## How to download:

1. Visit https://fonts.google.com/specimen/Inter
2. Download the font family
3. Extract and place the TTF files here

These fonts are used by the @vercel/og edge function to render OG images.
In production, you can also load fonts from a URL.
